# Cozy Trading Bot — Engineering Showcase

## Overview
An independently developed Python-based automated trading system focused on market analysis, risk management, trade execution, and system reliability.

## Key Features
- Automated trading signal analysis
- Dynamic position sizing and risk controls
- Market and pending-order execution workflows
- Duplicate trade prevention and reconciliation
- Multi-account monitoring
- Telegram notifications and system health reporting
- Automated testing and diagnostics

## Technologies
Python, MetaTrader 5, API integration, Windows VPS, and Telegram Bot API.

## Architecture
Market Data → Signal Evaluation → Risk Validation → Execution → Monitoring & Alerts

## Security
This public repository showcases the project's engineering concepts. Proprietary trading strategies, production source code, account credentials, and API keys remain private.

## Current Focus
Exploring how reliable automation, threat detection, and risk-monitoring principles can contribute to cybersecurity and AI safety.
